## Descripción
Este programa gestiona la entrada de datos individuales para construir una identidad completa. El script solicita el nombre y el apellido por separado, los almacena en variables independientes y finalmente los combina en una sola variable para generar un mensaje de bienvenida personalizado.

## Conceptos Aplicados
* **Captura de Strings**: Uso de la función `input()` para recibir datos de texto del usuario.
* **Concatenación de Cadenas**: Uso del operador `+` para unir múltiples strings en una sola estructura.
* **Manejo de Variables**: Almacenamiento y reutilización de datos para optimizar el flujo del programa.
* **Salida de Datos**: Presentación de resultados mediante la función `print()`.

## Ejemplo de Ejecución
1. **Entrada Nombre**: "Eder"
2. **Entrada Apellido**: "Hoppe"
3. **Proceso**: `Eder` + ` ` + `Hoppe`
4. **Resultado**: "Bienvenido Eder Hoppe"
